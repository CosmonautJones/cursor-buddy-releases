# Cursor Buddy for Windows

Download **`Cursor-Buddy-Setup-<version>.exe`** from the [latest release](https://github.com/CosmonautJones/cursor-buddy-releases/releases/latest) and run it. Buddy installs for your user only (no admin rights) and starts right away. After that, it updates itself.

The first time it runs, a Setup window:
1. downloads OpenAI's Codex CLI (about 180 MB, once) if you don't have it,
2. signs you in with ChatGPT (you need a ChatGPT plan: Plus, Pro, Business…),
3. checks your microphone and downloads the speech models (about 600 MB, once).

Then hold **Ctrl + Alt**, ask, and let go.

Windows may say "Windows protected your PC" because the installer isn't code-signed yet. Choose **More info → Run anyway**.

This repository only holds release files; the source is private.
